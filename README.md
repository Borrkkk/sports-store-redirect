# The Sports Store

A one-page announcement for The Sports Store's move from Upper Canada Mall in Newmarket to Aurora, and a look at what the new website is for.

The page is the news: after 32 years, the last day in the mall is Saturday, October 31. The Aurora street address is not published here, because it is not final. The signup list is for that address and for the website launch.

Coming with the site, and not for sale on this page:

- A webstore for licensed jerseys with a name and number sewn on
- A buy-and-sell vintage shop
- Those same custom jerseys in kids' sizes

## Run it

```bash
npm install
npm run dev
```

The dev server listens on port 4317. Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

The signup form checks the name and email on the server and confirms on the page. It does not store addresses.
